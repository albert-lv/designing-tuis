# Contributing to Designing TUIs

Thank you for helping improve this TUI design skill!

## What to Contribute

- New component definitions or disambiguation rules
- Additional framework mappings (e.g., Ratatui, Blessed, Rich)
- Workflow examples with before/after screenshots
- Color accessibility guidance or palette additions
- Corrections to layout inference rules

## How to Contribute

1. Fork the repository.
2. Create a branch: `git checkout -b propose/new-framework-mapping`
3. Make focused, well-explained changes.
4. Open a Pull Request with a summary and rationale.

## Style Guidelines

- Keep rules explicit and falsifiable.
- Prefer examples over abstract descriptions.
- Link to authoritative sources (WCAG, framework docs) where applicable.
- Maintain bilingual clarity if the original file is bilingual.
